# ai-toast-notify 实现计划（v1.4 修订版）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 ai-toast-notify v1 —— Windows 桌面 toast 通知 CLI，覆盖 Claude Code / Codex 的任务结束、异常、中断、等待用户操作事件。

**Architecture:** 无守护进程（方案 A）。三个入口：Claude Code hooks（settings.json，exec form + async）、Codex 新 hooks（~/.codex/hooks.json，command-string + async:true，stdin JSON；基线 codex-cli 0.166.0）、Codex 旧 notify（config.toml 回退，argv JSON）。统一 `send` 流水线：输入获取（argv 末参数 JSON 优先，否则 stdin）→ 识别来源 → 归一化 → 按用户配置过滤 → spawn PowerShell（原生 WinRT）发 toast → 记日志 → exit 0。

**Tech Stack:** TypeScript (strict, ESM) / Node.js >= 18 / vitest / PowerShell WinRT toast。**零运行时 npm 依赖**。

**Spec:** `docs/superpowers/specs/2026-11-02-ai-notify-design.md`

**v1.1 修订要点（相对 v1.0 计划）**：
1. 包名 `ai-notify` → **`ai-toast-notify`**（npm 撞名，发布阻断）
2. Codex 主路径改为**新 hooks 体系 hooks.json**（依据官方源码 + 本机在用文件），新增 Interrupt/PermissionRequest/SubagentStop 事件；旧 notify 降级为回退路径
3. **旧 notify payload 走 argv 末参数、stdin 为 null**（源码核实，v1.0 读 stdin 会导致 Codex 全挂）
4. Claude `StopFailure` 字段 `failure_reason` → **`error`/`error_details`**；`idle_ping` → **`idle_prompt`**
5. Claude `Stop` 处理 `background_tasks`/`session_crons`（非空 = 未真结束，跳过）并使用 `last_assistant_message`；未知 `notification_type` 兜底为 needs-input
6. Claude hook 改 **exec form（command+args）+ async: true**（规避 PowerShell 纯引号串不执行与引号地狱）
7. TOML `notify` 根键必须插在**首个 `[table]` 之前**；检测到他人 notify **跳过不覆盖**
8. toast 参数删除拼错的 `-WindowsStyle`（`windowsHide` 已足够）
9. install 测试 toast 改为 await

**v1.3 修订要点（基于本机 `codex-cli 0.166.0` 对应 `openai/codex@rust-v0.166.0` 源码复核）**：
1. **Codex hook 恢复 `async:true`**：0.166.0 源码 `discovery.rs` 判定 `async && event != SessionEnd` 即 async，`dispatcher.rs` 调用 `schedule_async_hook`，测试明确覆盖 Interrupt async；本项目不订阅 SessionEnd（Task 9）
2. **Codex Interrupt 事件 `async:true` + `timeout:3`**（上限 1–3 秒），其余自有 Codex hook `async:true` + `timeout:10`（Task 9）
3. **Codex hooks 事件总数为 14**：包含 PreModelRequest/PostModelRequest；v1 只挂载 Stop / Interrupt / PermissionRequest / PostModelRequest / SubagentStop 五个目标事件（Task 9）
4. **Codex Stop schema 无 `background_tasks`/`session_crons`**：这两个字段只作为 Claude Stop 判据；删除 Codex background fixture 与逻辑（Task 5）
5. **新增 Codex 异常通知**：只消费 PostModelRequest `status:"failed"` + `error`；completed/cancelled 返回 null，不订阅 PreModelRequest（Task 5/6/9/12/13）
6. **toast 内部超时分级**：interrupted 2500ms（Codex Interrupt 3 秒硬上限），其余 8000ms（宿主 10 秒）。本机实测 PowerShell+WinRT 常需 2.6–4.1 秒，Interrupt 在本机必现不可达，如实列为已知限制（Task 7/13）
7. **保留 v1.2 的正确修正**：`/hooks` hash 信任流程、`acceptEdits` fixture、PermissionRequest/Stop/SubagentStop 来源歧义处理、`messagePreview` 同步作用于两条 Codex 路径、orca 逐字保留、Task 12 自包含实现
8. **信任提示升级**：async/timeout/命令或路径变化都会改变 hook 定义 hash，需重新信任；从 v1.2 同步定义升级到 v1.3 async 定义同样需要重新信任（Task 9/12/13）

**v1.4 修订要点（基于隔离 CODEX_HOME 真机会话实测 + codex.exe 0.166.0 二进制字符串实证）**：
1. **确认 v1.3 全部事实主张成立**：async:true hook 真实执行（PostModelRequest 实测收到 stdin payload）；事件恰 14 种（二进制 `HookEventsToml` 枚举逐字核实）；Stop closed schema 无 `background_tasks`/`session_crons`（实测 payload + 二进制 0 命中）；`hook_event_name` 值为 PascalCase（实测 `"Stop"`/`"PostModelRequest"`）；payload 走 stdin（实测 472 字节）。官方 docs 的 "skips async handlers" 表述滞后于 0.166.0 实现
2. **修正 Codex command 模板**：0.166.0 Windows 矩阵实测 7 种形态——首个 token 必须是**裸可执行名**（`node`/`node.exe`，靠 PATH）；exe 带路径（正斜杠/反斜杠/8.3 短名）或加引号一律 `hook: Failed`（临时/非临时 CODEX_HOME 双重复现）。模板从 `"\"<node>\" \"<cli.js>\" send --codex"` 改为 **`node <cli.js> send --codex`**（路径无引号；cli.js 路径须无空格，npm 全局与 nvm 默认满足）（Task 9/12/13）
3. **恢复 Task 5 legacy 路径 `cwd` 缺失用例**（v1.3 无说明删除，属疏漏）
4. **新增已知限制第 10 条**：Codex Windows command 形态限制与 `where node` 排障（Task 13 README）；"经 cmd /C"的错误认知表述全部移除


## Global Constraints

- Node >= 18；`"type": "module"`；TypeScript `strict: true`；产物 `dist/`，bin 入口 `dist/cli.js`（带 shebang）
- 包名与 bin 名均为 **`ai-toast-notify`**；`package.json` 的 `files` 只含 `dist`
- **零运行时 npm 依赖**；dev 依赖仅 `typescript`、`vitest`、`@types/node`（TOML 用文本级修改）
- 通知文案简体中文；kind 用 emoji 前缀（✅ done / ❌ error / ⏹ interrupted / 💬 needs-input）
- **`send` 铁律**：任何输入、任何异常，永不抛未捕获错误、永以 exit 0 退出、stdout 恒为空（Codex PermissionRequest hook 会解析 stdout，空输出 + exit 0 = 不干预审批）
- 写 `settings.json` / `hooks.json` / `config.toml` 前**必须先备份**（`<原名>.bak.<YYYYMMDD-HHmmss>`）；只增删自有条目；幂等；**逐字保留第三方条目（如本机 orca 的 codex-hook.cmd）**
- Claude hook 一律 exec form：`{type:"command", command:"<node.exe>", args:["<cli.js>","send","--claude"], async:true, timeout:10}`
- Codex hooks.json 条目：`{type:"command", command:"node <cli.js> send --codex", async:true, timeout:10}`（**裸 `node` 名靠 PATH 解析，路径不加引号**——0.166.0 Windows 实测 exe 带路径/引号一律 `hook: Failed`；cli.js 路径须无空格，npm 全局与 nvm 默认满足）；**Interrupt 事件 `{async:true, timeout:3}`**（官方上限 3s）。Codex 事实以本机 codex-cli 0.166.0 为基线
- Codex hook 信任机制：install 后须在 Codex 内 `/hooks` 信任才执行；async/timeout/命令或升级（node/cli 路径变化）后定义 hash 变化，需重新信任——install 输出与 README 必提
- 平台目标 Windows 10/11；测试在本机 Windows 跑
- 用户数据目录 `~/.ai-toast-notify/`（config.json、log.txt）
- git 提交英文 conventional commits

```ts
import { appendFileSync, existsSync, rmSync, renameSync, statSync } from 'node:fs'
import { join } from 'node:path'

const MAX_BYTES = 1024 * 1024

/** 追加一行日志；任何 IO 异常吞掉（日志永远不能影响主流程）。 */
export function appendLog(dir: string, line: string): void {
  const file = join(dir, 'log.txt')
  try {
    if (existsSync(file) && statSync(file).size > MAX_BYTES) {
      const old = join(dir, 'log.txt.old')
      if (existsSync(old)) rmSync(old) // Windows 上 renameSync 目标已存在会报错，先删旧 .old
      renameSync(file, old)
    }
    appendFileSync(file, line + '\n')
  } catch {
    /* 日志失败静默 */
  }
}
```

```ts
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { dirname } from 'node:path'
import { DEFAULT_CONFIG, type UserConfig } from './types.js'

/** 读取用户配置；任何问题（缺文件/坏 JSON/字段缺失）逐层回退默认值，永不抛错。 */
export function loadConfig(path: string): UserConfig {
  try {
    if (!existsSync(path)) return structuredClone(DEFAULT_CONFIG)
    const raw = JSON.parse(readFileSync(path, 'utf8')) as Partial<UserConfig>
    return {
      events: { ...DEFAULT_CONFIG.events, ...raw.events },
      toast: { ...DEFAULT_CONFIG.toast, ...raw.toast },
      codex: { ...DEFAULT_CONFIG.codex, ...raw.codex },
    }
  } catch {
    return structuredClone(DEFAULT_CONFIG)
  }
}

/** 保存用户配置（自动建目录）。 */
export function saveConfig(path: string, cfg: UserConfig): void {
  mkdirSync(dirname(path), { recursive: true })
  writeFileSync(path, JSON.stringify(cfg, null, 2) + '\n')
}
```

  cwd?: string

  stop_hook_active?: boolean

  return s.trim().length > PREVIEW_LEN ? s.trim().slice(0, PREVIEW_LEN) : s.trim()
}

function backgroundWork(input: ClaudeHookInput): boolean {
  return (Array.isArray(input.background_tasks) && input.background_tasks.length > 0)
    || (Array.isArray(input.session_crons) && input.session_crons.length > 0)
}

export function parseClaudeEvent(input: ClaudeHookInput): NotifyEvent | null {
  const cwd = typeof input.cwd === 'string' ? input.cwd : ''
  const title = `Claude Code · ${cwd ? basename(cwd) : '未知目录'}`

  switch (input.hook_event_name) {
    case 'Stop':
      if (backgroundWork(input)) return null
      return { source: 'claude-code', kind: 'done', title, cwd,
               detail: trim(input.last_assistant_message) ?? '任务完成，等你查看' }

    case 'SubagentStop':
      return { source: 'claude-code', kind: 'done', title, cwd,
               detail: trim(input.last_assistant_message) ?? '子代理任务完成', filterKey: 'subagentStop' }

    case 'StopFailure':
      return { source: 'claude-code', kind: 'error', title, cwd,
               detail: `出错停止：${input.error ?? '未知原因'}${input.error_details ? `（${input.error_details}）` : ''}` }

    case 'PostToolUseFailure':
      // 官方：用户取消运行中的工具不触发此 hook；is_interrupt=true 仅覆盖 abort 形态
      if (input.is_interrupt !== true) return null
      return { source: 'claude-code', kind: 'interrupted', title, cwd, detail: '工具以中断方式结束' }

    case 'Notification': {
      const type = input.notification_type
      const message = input.message ?? ''
      if (type === 'permission_prompt' || (!type && /permission/i.test(message)))
        return { source: 'claude-code', kind: 'needs-input', title, cwd, detail: '等待你批准工具调用' }
      if (type === 'agent_needs_input' || (!type && /waiting for your input/i.test(message)))
        return { source: 'claude-code', kind: 'needs-input', title, cwd, detail: '在等你输入' }
      if (type === 'idle_prompt' || type === 'idle_ping' || (!type && /idle/i.test(message)))
        return { source: 'claude-code', kind: 'needs-input', title, cwd, detail: '空闲提醒', filterKey: 'idlePing' }
      // 未知类型兜底 needs-input：Claude 未来新增权限类事件绝不静默漏报（anotifier 同策略）
      return { source: 'claude-code', kind: 'needs-input', title, cwd,
               detail: trim(message) ?? `Claude 通知（${type ?? '未知类型'}）` }
    }

    default:
      return null
  }

import { spawn } from 'node:child_process'
import type { NotifyEvent } from '../types.js'

export const POWERSHELL_EXE = 'powershell.exe'
export const TOAST_TIMEOUT_INTERRUPTED_MS = 2500 // Interrupt 宿主 3s 硬上限
export const TOAST_TIMEOUT_DEFAULT_MS = 8000 // 其余事件宿主 10s 上限

/** 系统 PowerShell 开始菜单快捷方式 AUMID（soulee-dev / TianqiZhang 同款，Win10/11 稳定存在） */
const APP_ID = '{1AC14E77-02E7-4E5D-B744-2EB1AE5198B7}\\WindowsPowerShell\\v1.0\\powershell.exe'

const KIND_EMOJI: Record<NotifyEvent['kind'], string> = {
  done: '✅', error: '❌', interrupted: '⏹', 'needs-input': '💬',
}

export function escapeXml(s: string): string {
  return s.replaceAll('&', '&amp;').replaceAll('<', '&lt;').replaceAll('>', '&gt;')
          .replaceAll('"', '&quot;').replaceAll("'", '&apos;')
}

export function buildToastArgs(event: NotifyEvent, opts: { sound: boolean }): string[] {
  const title = escapeXml(`${KIND_EMOJI[event.kind]} ${event.title}`)
  const detail = escapeXml(event.detail ?? '')
  const audio = opts.sound ? '' : '<audio silent="true"/>'
  const script = [
    "$ErrorActionPreference='Stop'",
    'try {',
    '  $null=[Windows.UI.Notifications.ToastNotificationManager, Windows.UI.Notifications, ContentType=WindowsRuntime]',
    '  $null=[Windows.Data.Xml.Dom.XmlDocument, Windows.Data.Xml.Dom.XmlDocument, ContentType=WindowsRuntime]',
    `  $xml='<toast><visual><binding template="ToastGeneric"><text>${title}</text><text>${detail}</text></binding></visual>${audio}</toast>'`,
    '  $doc=New-Object Windows.Data.Xml.Dom.XmlDocument',
    '  $doc.LoadXml($xml)',
    '  $t=New-Object Windows.UI.Notifications.ToastNotification $doc',
    `  [Windows.UI.Notifications.ToastNotificationManager]::CreateToastNotifier('${APP_ID}').Show($t)`,
    '} catch { exit 1 }',
  ].join('\n')
  // 注意：不传 -WindowStyle（v1.0 的 -WindowsStyle 是拼写错误；windowsHide 已隐藏控制台）
  return ['-NoProfile', '-NonInteractive', '-ExecutionPolicy', 'Bypass', '-Command', script]
}

export function sendToast(event: NotifyEvent, opts: { sound: boolean }): Promise<void> {
  return new Promise((resolve, reject) => {
    const child = spawn(POWERSHELL_EXE, buildToastArgs(event, opts), {
      timeout: event.kind === 'interrupted' ? TOAST_TIMEOUT_INTERRUPTED_MS : TOAST_TIMEOUT_DEFAULT_MS,
      windowsHide: true,
    })
    child.on('error', reject)
    child.on('close', (code) => (code === 0 ? resolve() : reject(new Error(`powershell exited with ${code}`))))
  })
}

import { CLAUDE_HOOK_EVENTS } from './events.js'

export { CLAUDE_HOOK_EVENTS }

interface HookEntry {
  type?: string
  command?: string
  args?: string[]
  [k: string]: unknown
}
interface HookGroup { matcher?: string; hooks: HookEntry[] }
type HooksMap = Record<string, HookGroup[]>

export function buildClaudeHookEntry(nodePath: string, cliJsPath: string): HookEntry {
  return {
    type: 'command',
    command: nodePath,                      // exec form：裸 node.exe 绝对路径，无 shell、无引号问题
    args: [cliJsPath, 'send', '--claude'],  // 逐元素传递，空格路径天然安全
    async: true,                            // Claude 支持 async，不阻塞回合
    timeout: 10,
  }
}

/** 按结构识别自有 hook：args 含包名与 'send'（路径升级变化也能识别，不做字符串全等比对） */
export function isAiNotifyClaudeHook(h: unknown): boolean {
  if (typeof h !== 'object' || h === null) return false
  const e = h as HookEntry
  return e.type === 'command'
    && Array.isArray(e.args)
    && e.args.some((a) => typeof a === 'string' && a.includes(PKG_NAME))
    && e.args.includes('send')
}

export function mergeClaudeHooks(
  settings: Record<string, unknown>,
  nodePath: string,
  cliJsPath: string,
): Record<string, unknown> {
  const out = structuredClone(settings)
  const hooks = (out.hooks ?? {}) as HooksMap
  const entry = buildClaudeHookEntry(nodePath, cliJsPath)
  for (const ev of CLAUDE_HOOK_EVENTS) {
    const groups = (hooks[ev] ?? []) as HookGroup[]
    // 先剔除旧的自有条目（升级换路径场景），再追加新组
    for (const g of groups) g.hooks = g.hooks.filter((h) => !isAiNotifyClaudeHook(h))
    const cleaned = groups.filter((g) => g.hooks.length > 0)
    cleaned.push({ matcher: '', hooks: [entry] })
    hooks[ev] = cleaned
  }
  out.hooks = hooks
  return out
}

export function removeClaudeHooks(settings: Record<string, unknown>): Record<string, unknown> {
  const out = structuredClone(settings)
  const hooks = out.hooks as HooksMap | undefined
  if (!hooks) return out
  for (const ev of Object.keys(hooks)) {
    const groups = hooks[ev] ?? []
    for (const g of groups) g.hooks = g.hooks.filter((h) => !isAiNotifyClaudeHook(h))
    const cleaned = groups.filter((g) => g.hooks.length > 0)
    if (cleaned.length > 0) hooks[ev] = cleaned
    else delete hooks[ev]
  }
  if (Object.keys(hooks).length === 0) delete out.hooks
  return out
}

  return `${d.getFullYear()}${p(d.getMonth() + 1)}${p(d.getDate())}-${p(d.getHours())}${p(d.getMinutes())}${p(d.getSeconds())}`
}

      ? (JSON.parse(readFileSync(settingsPath, 'utf8')) as Record<string, unknown>)
      : {}
  } catch (err) {

}

const NOTIFY_LINE = /^notify\s*=\s*\[[^\[\]]*\]\s*$/m

export function mergeCodexNotify(tomlText: string, nodePath: string, cliJsPath: string): { text: string; skipped: boolean } {
  const line = `notify = ${toTomlArray(buildNotifyValue(nodePath, cliJsPath))}`
  const m = tomlText.match(NOTIFY_LINE)
  if (m) {
    if (m[0].includes(PKG_NAME)) return { text: tomlText.replace(NOTIFY_LINE, line), skipped: false } // 自有 → 替换
    return { text: tomlText, skipped: true }                                            // 他人 → 跳过不覆盖
  }
  if (/^notify\s*=/m.test(tomlText))
    throw new Error('config.toml 已有 notify 键但不是可识别的单行数组形态，请手动处理')

  const tableIdx = tomlText.search(/^\s*\[/m) // 首个 [table]：根键必须插在它之前
  if (tableIdx === -1) {
    const base = tomlText.replace(/\s*$/, '')
    return { text: base ? `${base}\n${line}\n` : `${line}\n`, skipped: false }
  }
  const head = tomlText.slice(0, tableIdx).replace(/\s*$/, '')
  const tail = tomlText.slice(tableIdx)
  return { text: `${head}\n${line}\n\n${tail}`, skipped: false }
}

  const log = (msg: string) => deps.appendLog(deps.logDir, `${new Date().toISOString()} ${msg}`)
  try {
    const rawArgv = extractArgvJson(argv)
    const raw = rawArgv ?? await deps.readStdin(process.stdin, STDIN_TIMEOUT_MS)
    if (!raw.trim()) { log('send: empty input, ignore'); return }
    let payload: unknown
    try { payload = JSON.parse(raw) } catch { log('send: invalid json, ignore'); return }

    const cfg = deps.loadConfig(configPath())
    const source = detectSource(argv, payload)
    if (!source) { log('send: source not detected, ignore'); return }

    let event: NotifyEvent | null = null
    if (source === 'claude-code') {
      event = parseClaudeEvent(payload as ClaudeHookInput)
    } else if (payload && (payload as CodexLegacyInput).type === 'agent-turn-complete') {
      event = parseCodexLegacyNotify(payload as CodexLegacyInput, deps.cwd ?? process.cwd(),

    } else {
      event = parseCodexHookEvent(payload as CodexHookInput, deps.cwd ?? process.cwd(),
        { messagePreview: cfg.codex.messagePreview })

    if (!event) { log(`send: ${source} event not notifiable, ignore`); return }
    if (event.filterKey && !cfg.events[event.filterKey]) { log(`send: ${event.filterKey} off, drop`); return }

    await deps.sendToast(event, { sound: cfg.toast.sound })
    log(`send: ${event.source} ${event.kind} toast ok`)
  } catch (err) {

### v1.4 执行期修订（真机验收发现，测试同步更新）

1. **toast 内部超时分级**：`interrupted` 保持 2500ms（Codex Interrupt 宿主 3s 硬上限），其余事件提为 8000ms（宿主 10s）。原因：本机 PowerShell+WinRT 实测 2.6–4.1s，统一 2500ms 导致 toast 100% 超时失败
2. **自有 hook 识别改为路径无关结构特征**：Claude `args` 末尾恰为 `['send','--claude']`；Codex `command` 以 `send --codex` 结尾。原因：npm link / 任意目录名安装时 cli 路径不含包名，按 PKG_NAME 识别导致幂等与卸载失效
3. **新机器父目录自动创建**（`~/.claude`、`~/.codex` 可能不存在，原实现直接 ENOENT）
4. **config.toml NOTIFY_LINE 正则排除换行**：多行 notify 正确抛错，不再被误判为"他人单行 notify"跳过
5. **CLI 直接执行守卫改用 realpathSync**：修复 npm link 符号链接下 argv[1] 与 import.meta.url 不一致导致 main 不执行
