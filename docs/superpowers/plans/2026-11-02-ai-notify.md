# ai-notify 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 ai-notify v1 —— Windows 桌面 toast 通知 CLI，覆盖 Claude Code / Codex 的任务结束、异常、中断、等待用户操作事件。

**Architecture:** 无守护进程（方案 A）。`ai-notify send` 被 Claude Code hooks 与 Codex `notify` 配置调用：读 stdin JSON → 识别来源 → 解析归一化为 `NotifyEvent` → 按用户配置过滤 → spawn PowerShell（原生 WinRT API）发 toast → 记日志 → exit 0。`install`/`uninstall` 增量修改两个 CLI 的配置文件（写前备份、幂等、只动自有条目）。

**Tech Stack:** TypeScript (strict, ESM) / Node.js >= 18 / vitest / PowerShell WinRT toast。**零运行时 npm 依赖**。

**Spec:** `docs/superpowers/specs/2026-11-02-ai-notify-design.md`

## Global Constraints

- Node >= 18；`"type": "module"`；TypeScript `strict: true`；编译产物 `dist/`，bin 入口 `dist/cli.js`（带 shebang）
- **零运行时 npm 依赖**（TOML 用文本级修改，见 Task 9）；dev 依赖仅 `typescript`、`vitest`、`@types/node`
- 包名与 bin 名均为 `ai-notify`；`package.json` 的 `files` 只含 `dist`
- **通知文案简体中文**，按 spec 4.3 文案表；kind 视觉区分用 emoji 前缀（✅ done / ❌ error / ⏹ interrupted / 💬 needs-input）——这是对 spec"error 红色系"的低风险等效实现（ToastGeneric 红色需 adaptive XML，Windows 版本兼容差），在 README 注明
- **`send` 命令铁律**：任何输入、任何异常，永不抛未捕获错误、永以 `exit 0` 退出
- 写 `settings.json` / `config.toml` 前**必须先备份**（`<原名>.bak.<YYYYMMDD-HHmmss>`）；只增删自有条目，幂等
- hook/notify command 一律用绝对路径：`"<process.execPath>" "<cliJs 绝对路径>" send`（不依赖 PATH，防 shim/引号问题）
- 平台目标 Windows 10/11；全部测试在本机 Windows 上跑
- 用户数据目录 `~/.ai-notify/`（config.json、log.txt）
- git 提交信息用英文 conventional commits（feat:/test:/docs:/chore:）

## Review Focus

spec 未显式测试、但最可能咬到真实用户的五类输入（每条已把测试钉进所属任务）：

1. **stdin 是非法 JSON 或空**（CLI 传坏数据、用户手敲调试）→ 应记日志并安静 exit 0，不崩 → 测试在 Task 10（`runSend` 坏 JSON 用例）
2. **stdin 永不关闭**（调用方异常）→ 3 秒超时后按已读内容处理，不挂死 → 测试在 Task 10（`readStdin` 超时用例，fake stream 不 end）
3. **toast 文本含 XML 特殊字符/中文/emoji**（`& < > " '`、目录名如 `R&D`）→ 必须转义，toast 仍可弹 → 测试在 Task 7（`escapeXml` 用例）
4. **安装路径含空格**（`C:\Program Files\...`）→ 生成的 command 引号必须正确 → 测试在 Task 8 与 Task 9（空格路径用例）
5. **config.toml 已有 `notify` 且为多行数组等罕见形态** → 拒绝盲改（抛错提示手动处理），绝不出产重复键的坏文件 → 测试在 Task 9（多行 notify 抛错用例）

```ts
import { appendFileSync, existsSync, renameSync, statSync } from 'node:fs'
import { join } from 'node:path'

const MAX_BYTES = 1024 * 1024

/** 追加一行日志；任何 IO 异常吞掉（日志永远不能影响主流程）。 */
export function appendLog(dir: string, line: string): void {
  const file = join(dir, 'log.txt')
  try {
    if (existsSync(file) && statSync(file).size > MAX_BYTES) {
      const old = join(dir, 'log.txt.old')
      if (existsSync(old)) renameSync(old, old) // no-op 占位，真正删除旧 .old 在下一行覆盖
      renameSync(file, join(dir, 'log.txt.old'))
    }
    appendFileSync(file, line + '\n')
  } catch {
    /* 日志失败静默 */
  }
}
```

注意：`renameSync` 在目标已存在时（Windows）会报错，所以先删旧 `.old`：

```ts
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { dirname } from 'node:path'
import { DEFAULT_CONFIG, type UserConfig } from './types.js'

/** 读取用户配置；任何问题（缺文件/坏 JSON/字段缺失）逐层回退默认值，永不抛错。 */
export function loadConfig(path: string): UserConfig {
  try {
    if (!existsSync(path)) return structuredClone(DEFAULT_CONFIG)
    const raw = JSON.parse(readFileSync(path, 'utf8')) as Partial<UserConfig>
    return {
      events: { ...DEFAULT_CONFIG.events, ...raw.events },
      toast: { ...DEFAULT_CONFIG.toast, ...raw.toast },
      codex: { ...DEFAULT_CONFIG.codex, ...raw.codex },
    }
  } catch {
    return structuredClone(DEFAULT_CONFIG)
  }
}

/** 保存用户配置（自动建目录）。 */
export function saveConfig(path: string, cfg: UserConfig): void {
  mkdirSync(dirname(path), { recursive: true })
  writeFileSync(path, JSON.stringify(cfg, null, 2) + '\n')
}
```

```ts
import { basename } from 'node:path'
import type { NotifyEvent } from '../types.js'

/** Claude Code hook stdin JSON 的宽松形态（未知字段容忍）。 */
export interface ClaudeHookInput {
  hook_event_name?: string
  cwd?: string
  message?: string
  notification_type?: string
  failure_reason?: string
  is_interrupt?: boolean
  [k: string]: unknown
}

/**
 * 解析 Claude Code hook 事件为归一化事件。
 * 返回 null = 不通知（未知事件 / 非中断的工具失败）。
 */
export function parseClaudeEvent(input: ClaudeHookInput): NotifyEvent | null {
  const cwd = typeof input.cwd === 'string' ? input.cwd : ''
  const title = `Claude Code · ${cwd ? basename(cwd) : '未知目录'}`

  switch (input.hook_event_name) {
    case 'Stop':
      return { source: 'claude-code', kind: 'done', title, detail: '任务完成，等你查看', cwd }

    case 'SubagentStop':
      return {
        source: 'claude-code', kind: 'done', title,
        detail: '子代理任务完成', cwd, filterKey: 'subagentStop',
      }

    case 'StopFailure':
      return {
        source: 'claude-code',
        kind: 'error',
        title,
        detail: `出错停止：${input.failure_reason ?? '未知原因'}`,
        cwd,
      }

    case 'PostToolUseFailure':
      if (input.is_interrupt !== true) return null
      return { source: 'claude-code', kind: 'interrupted', title, detail: '任务被中断', cwd }

    case 'Notification': {
      const type = input.notification_type
      const message = input.message ?? ''
      if (type === 'permission_prompt' || (!type && message.includes('permission'))) {
        return { source: 'claude-code', kind: 'needs-input', title, detail: '等待你批准工具调用', cwd }
      }
      if (type === 'agent_needs_input' || (!type && message.includes('waiting for your input'))) {
        return { source: 'claude-code', kind: 'needs-input', title, detail: '在等你输入', cwd }
      }
      if (type === 'idle_ping' || (!type && message.includes('idle'))) {
        return { source: 'claude-code', kind: 'needs-input', title, detail: '空闲提醒', cwd, filterKey: 'idlePing' }
      }
      return null
    }

    default:
      return null
  }
}
```

```ts
import { basename } from 'node:path'
import type { NotifyEvent } from '../types.js'

/** Codex notify payload 的宽松形态。 */
export interface CodexNotifyInput {
  type?: string
  cwd?: string
  'last-assistant-message'?: string
  [k: string]: unknown
}

const PREVIEW_LEN = 80

/** 解析 Codex notify 事件；返回 null = 不通知。 */
export function parseCodexEvent(
  input: CodexNotifyInput,
  fallbackCwd: string,
  opts: { messagePreview: boolean },
): NotifyEvent | null {
  if (input.type !== 'agent-turn-complete') return null

  const cwd = typeof input.cwd === 'string' && input.cwd ? input.cwd : fallbackCwd
  const title = `Codex · ${cwd ? basename(cwd) : '未知目录'}`

  let detail: string | undefined
  const msg = typeof input['last-assistant-message'] === 'string'
    ? (input['last-assistant-message'] as string)
    : ''
  if (opts.messagePreview && msg) {
    detail = msg.length > PREVIEW_LEN ? msg.slice(0, PREVIEW_LEN) : msg
  }
  if (!detail) detail = '任务完成，等你查看'

  return { source: 'codex', kind: 'done', title, detail, cwd }
}
```

```ts
/** 识别 stdin payload 来自哪个 CLI；识别不了返回 null（send 层记日志后安静退出）。 */
export function detectSource(argv: string[], payload: unknown): EventSource | null {
  if (argv.includes('--codex')) return 'codex'

  }
  return null
}
```

```ts
import { spawn } from 'node:child_process'
import type { NotifyEvent } from '../types.js'

export const POWERSHELL_EXE = 'powershell.exe'
export const TOAST_TIMEOUT_MS = 5000

/** PowerShell 的 AUMID（开始菜单快捷方式自带，Win10/11 稳定存在；BurntToast 同款做法）。 */
const APP_ID = '{1AC14E77-02E7-4E5D-B744-2EB1AE5198B7}\\WindowsPowerShell\\v1.0\\powershell.exe'

const KIND_EMOJI: Record<NotifyEvent['kind'], string> = {
  done: '✅',
  error: '❌',
  interrupted: '⏹',
  'needs-input': '💬',
}

export function escapeXml(s: string): string {
  return s
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;')
    .replaceAll("'", '&apos;')
}

export function buildToastArgs(event: NotifyEvent, opts: { sound: boolean }): string[] {
  const emoji = KIND_EMOJI[event.kind]
  const title = escapeXml(`${emoji} ${event.title}`)
  const detail = escapeXml(event.detail ?? '')
  const audio = opts.sound ? '' : '<audio silent="true"/>'
  const script = [
    "$ErrorActionPreference='Stop'",
    'try {',
    '  $null=[Windows.UI.Notifications.ToastNotificationManager, Windows.UI.Notifications, ContentType=WindowsRuntime]',
    '  $null=[Windows.Data.Xml.Dom.XmlDocument, Windows.Data.Xml.Dom.XmlDocument, ContentType=WindowsRuntime]',
    `  $xml='<toast><visual><binding template="ToastGeneric"><text>${title}</text><text>${detail}</text></binding></visual>${audio}</toast>'`,
    '  $doc=New-Object Windows.Data.Xml.Dom.XmlDocument',
    '  $doc.LoadXml($xml)',
    '  $t=New-Object Windows.UI.Notifications.ToastNotification $doc',
    `  [Windows.UI.Notifications.ToastNotificationManager]::CreateToastNotifier('${APP_ID}').Show($t)`,
    '} catch { exit 1 }',
  ].join('\n')
  return ['-NoProfile', '-NonInteractive', '-ExecutionPolicy', 'Bypass', '-WindowsStyle', 'Hidden', '-Command', script]
}

/** 发送 toast；失败/超时 reject（调用方吞掉并记日志）。 */
export function sendToast(event: NotifyEvent, opts: { sound: boolean }): Promise<void> {
  return new Promise((resolve, reject) => {
    const child = spawn(POWERSHELL_EXE, buildToastArgs(event, opts), {
      timeout: TOAST_TIMEOUT_MS,
      windowsHide: true,
    })
    child.on('error', (err) => reject(err))
    child.on('close', (code) => {
      if (code === 0) resolve()
      else reject(new Error(`powershell exited with ${code}`))
    })
  })
}
```

```ts
import { HOOK_EVENTS } from './events.js'

export { HOOK_EVENTS }

interface HookEntry { type: string; command: string }
interface HookGroup { matcher: string; hooks: HookEntry[] }
type HooksMap = Record<string, HookGroup[]>

export function buildHookCommand(nodePath: string, cliJsPath: string): string {
  return `"${nodePath}" "${cliJsPath}" send`
}

export function isAiNotifyCommand(cmd: string): boolean {
  return /"[^"]*ai-notify[^"]*"\s+send$/.test(cmd)
}

export function mergeClaudeHooks(
  settings: Record<string, unknown>,
  nodePath: string,
  cliJsPath: string,
): Record<string, unknown> {
  const out = structuredClone(settings) as Record<string, unknown>
  const hooks = (out.hooks ?? {}) as HooksMap
  const ourCommand = buildHookCommand(nodePath, cliJsPath)

  for (const ev of HOOK_EVENTS) {
    const groups = (hooks[ev] ?? []) as HookGroup[]
    // 先剔除旧的自有条目（升级换路径场景），再追加新的
    for (const g of groups) g.hooks = g.hooks.filter((h) => !isAiNotifyCommand(h.command))
    const cleaned = groups.filter((g) => g.hooks.length > 0)
    cleaned.push({ matcher: '', hooks: [{ type: 'command', command: ourCommand }] })
    hooks[ev] = cleaned
  }
  out.hooks = hooks
  return out
}

export function removeClaudeHooks(settings: Record<string, unknown>): Record<string, unknown> {
  const out = structuredClone(settings) as Record<string, unknown>
  const hooks = out.hooks as HooksMap | undefined
  if (!hooks) return out
  for (const ev of Object.keys(hooks)) {
    const groups = hooks[ev] ?? []
    for (const g of groups) g.hooks = g.hooks.filter((h) => !isAiNotifyCommand(h.command))
    const cleaned = groups.filter((g) => g.hooks.length > 0)
    if (cleaned.length > 0) hooks[ev] = cleaned
    else delete hooks[ev]
  }
  if (Object.keys(hooks).length === 0) delete out.hooks
  return out
}

/** 时间戳备份后缀。 */
function backupSuffix(d = new Date()): string {
  const p = (n: number) => String(n).padStart(2, '0')
  return `${d.getFullYear()}${p(d.getMonth() + 1)}${p(d.getDate())}-${p(d.getHours())}${p(d.getMinutes())}${p(d.getSeconds())}`
}

export function installClaudeConfig(settingsPath: string, nodePath: string, cliJsPath: string): void {
  let settings: Record<string, unknown>
  try {
    settings = existsSync(settingsPath)
      ? (JSON.parse(readFileSync(settingsPath, 'utf8')) as Record<string, unknown>)
      : {}
  } catch (err) {
    throw new Error(`settings.json 解析失败，拒绝写入：${settingsPath}（${(err as Error).message}）`)
  }
  const merged = mergeClaudeHooks(settings, nodePath, cliJsPath)
  if (existsSync(settingsPath)) copyFileSync(settingsPath, `${settingsPath}.bak.${backupSuffix()}`)
  writeFileSync(settingsPath, JSON.stringify(merged, null, 2) + '\n')
}

export function uninstallClaudeConfig(settingsPath: string): void {

  let settings: Record<string, unknown>

  } catch (err) {
    throw new Error(`settings.json 解析失败，拒绝写入：${settingsPath}（${(err as Error).message}）`)
  }
  const cleaned = removeClaudeHooks(settings)
  copyFileSync(settingsPath, `${settingsPath}.bak.${backupSuffix()}`)
  writeFileSync(settingsPath, JSON.stringify(cleaned, null, 2) + '\n')
}
```

```ts
export function buildNotifyValue(nodePath: string, cliJsPath: string): string[] {
  return [nodePath, cliJsPath, 'send', '--codex']

/** 字符串数组 → TOML 单行数组文本（基本字符串转义：反斜杠与双引号）。 */
export function toTomlArray(items: string[]): string {
  const escaped = items.map((s) => `"${s.replaceAll('\\', '\\\\').replaceAll('"', '\\"')}"`)
  return `[${escaped.join(', ')}]`
}

// 单行 notify 键（我们维护的唯一形态）。多行形态不匹配 → 抛错防重复键。
const NOTIFY_LINE = /^notify\s*=\s*\[[^\[\]]*\]\s*$/m

export function mergeCodexNotify(tomlText: string, nodePath: string, cliJsPath: string): string {
  const line = `notify = ${toTomlArray(buildNotifyValue(nodePath, cliJsPath))}`
  if (!NOTIFY_LINE.test(tomlText)) {
    if (/^notify\s*=/m.test(tomlText)) {
      throw new Error('config.toml 已有 notify 键但不是可识别的单行数组形态，请手动改为单行或删除后重试')
    }
    const base = tomlText.replace(/\s*$/, '')
    return base ? `${base}\n${line}\n` : `${line}\n`
  }
  return tomlText.replace(NOTIFY_LINE, line)
}

export function removeCodexNotify(tomlText: string): string {
  const m = tomlText.match(NOTIFY_LINE)
  if (!m || !m[0].includes('ai-notify')) return tomlText
  return tomlText.replace(NOTIFY_LINE, '').replace(/^\s+/, '').replace(/\n{3,}/g, '\n\n')
}

function backupSuffix(d = new Date()): string {
  const p = (n: number) => String(n).padStart(2, '0')
  return `${d.getFullYear()}${p(d.getMonth() + 1)}${p(d.getDate())}-${p(d.getHours())}${p(d.getMinutes())}${p(d.getSeconds())}`
}

export function installCodexConfig(configPath: string, nodePath: string, cliJsPath: string): void {
  const original = existsSync(configPath) ? readFileSync(configPath, 'utf8') : ''
  const updated = mergeCodexNotify(original, nodePath, cliJsPath) // 抛错则不写
  if (existsSync(configPath)) copyFileSync(configPath, `${configPath}.bak.${backupSuffix()}`)
  writeFileSync(configPath, updated)
}

export function uninstallCodexConfig(configPath: string): void {
  if (!existsSync(configPath)) return
  const original = readFileSync(configPath, 'utf8')
  const updated = removeCodexNotify(original)
  if (updated === original) return
  copyFileSync(configPath, `${configPath}.bak.${backupSuffix()}`)
  writeFileSync(configPath, updated)
}
```

```ts
/** 读尽 stream；超时则按已读内容返回（防调用方不关 stdin 挂死 send）。 */
export function readStdin(stream: NodeJS.ReadableStream, timeoutMs: number): Promise<string> {
  return new Promise((resolve) => {
    let data = ''
    const done = (v: string) => {
      stream.removeListener('data', onData)
      stream.removeListener('end', onEnd)
      stream.removeListener('error', onEnd)
      resolve(v)
    }
    const onData = (chunk: Buffer | string) => { data += chunk.toString() }
    const onEnd = () => done(data)
    stream.on('data', onData)
    stream.on('end', onEnd)
    stream.on('error', onEnd)
    setTimeout(() => done(data), timeoutMs).unref()
  })
}
```

```ts
import { fileURLToPath, pathToFileURL } from 'node:url'
import { homedir } from 'node:os'
import { join } from 'node:path'

import { parseClaudeEvent } from './adapters/claude.js'
import { parseCodexEvent } from './adapters/codex.js'
import { detectSource } from './adapters/detect.js'
import { sendToast } from './notify/toast.js'
import { loadConfig, saveConfig } from './config.js'
import { DEFAULT_CONFIG } from './types.js'
import { appendLog } from './log.js'
import {
  installClaudeConfig, uninstallClaudeConfig,

  installCodexConfig, uninstallCodexConfig,

const STDIN_TIMEOUT_MS = 3000

export function dataDir(): string { return join(homedir(), '.ai-notify') }
export function claudeSettingsPath(): string { return join(homedir(), '.claude', 'settings.json') }
export function codexConfigPath(): string { return join(homedir(), '.codex', 'config.toml') }
export function configPath(): string { return join(dataDir(), 'config.json') }
/** 自身 cli.js 的绝对路径（无论从哪个 shim 调用都真实）。 */
export function cliJsPath(): string { return fileURLToPath(import.meta.url) }

export interface SendDeps {
  readStdin: (stream: NodeJS.ReadableStream, timeoutMs: number) => Promise<string>
  sendToast: (event: NotifyEvent, opts: { sound: boolean }) => Promise<void>
  appendLog: (dir: string, line: string) => void
  loadConfig: (path: string) => UserConfig
  logDir: string
  cwd?: string
}

/** send 流水线：任何失败只记日志，永不抛错（由 main 兜底 exit 0）。 */
export async function runSend(argv: string[], deps: SendDeps): Promise<void> {
  const log = (msg: string) => deps.appendLog(deps.logDir, `${new Date().toISOString()} ${msg}`)
  let payload: unknown
  try {
    const raw = await deps.readStdin(process.stdin, STDIN_TIMEOUT_MS)
    if (!raw.trim()) { log('send: empty stdin, ignore'); return }
    try { payload = JSON.parse(raw) } catch { log('send: invalid json, ignore'); return }

    const cfg = deps.loadConfig(configPath())
    const source = detectSource(argv, payload)
    if (!source) { log('send: source not detected, ignore'); return }

    let event: NotifyEvent | null = null
    if (source === 'claude-code') {
      event = parseClaudeEvent(payload as Record<string, unknown>)
    } else {
      const fallbackCwd = deps.cwd ?? process.cwd()
      event = parseCodexEvent(payload as Record<string, unknown>, fallbackCwd, { messagePreview: cfg.codex.messagePreview })
    }
    if (!event) { log(`send: ${source} event not notifiable, ignore`); return }
    if (event.filterKey && !cfg.events[event.filterKey]) { log(`send: ${event.filterKey} off by config, drop`); return }

    await deps.sendToast(event, { sound: cfg.toast.sound })
    log(`send: ${event.source} ${event.kind} toast ok`)
  } catch (err) {
    log(`send: FAILED ${(err as Error).message}`)
  }
}

function cmdInstall(): void {
  const node = process.execPath
  const cli = cliJsPath()
  console.log(`安装 ai-notify…\n  node: ${node}\n  cli:  ${cli}`)

  console.log(`✓ Claude Code hooks 已写入 ${claudeSettingsPath()}`)
  installCodexConfig(codexConfigPath(), node, cli)
  console.log(`✓ Codex notify 已写入 ${codexConfigPath()}`)
  if (!existsSync(configPath())) saveConfig(configPath(), DEFAULT_CONFIG)
  console.log(`✓ 用户配置 ${configPath()}`)
  sendToast(
    { source: 'claude-code', kind: 'done', title: 'ai-notify', detail: '安装成功！这条通知就是它发的 🎉', cwd: process.cwd() },
    { sound: true },
  ).then(
    () => console.log('✓ 测试通知已发送，请看屏幕右下角'),
    (err) => console.error(`✗ 测试通知失败：${(err as Error).message}（检查 Windows 通知设置）`),
  )
}

function cmdUninstall(): void {

  uninstallCodexConfig(codexConfigPath())
  console.log(`✓ Codex notify 已移除`)
  console.log(`~ ${dataDir()} 目录保留（含日志），可手动删除`)
}

async function cmdTest(): Promise<void> {
  await sendToast(

    { sound: true },
  )
  console.log('✓ 测试通知已发送')
}

export async function main(): Promise<void> {
  const [cmd, ...rest] = process.argv.slice(2)
  switch (cmd) {
    case 'install': cmdInstall(); break
    case 'uninstall': cmdUninstall(); break
    case 'send': await runSend(['send', ...rest], {
      readStdin, sendToast, appendLog, loadConfig, logDir: dataDir(), cwd: process.cwd(),
    }); break
    case 'test': await cmdTest().catch((e) => console.error(`✗ ${(e as Error).message}`)); break
    default:
      console.log('ai-notify — Claude Code / Codex 任务通知\n\n用法：ai-notify install | uninstall | send [--codex] | test')
      if (cmd !== undefined) process.exitCode = 1
  }
}
```

```markdown
# ai-notify

Claude Code / Codex 任务结束、异常、中断、等待操作时，弹 Windows 桌面通知。

## 安装
npm install -g ai-notify
ai-notify install      # 自动配置两个 CLI，并弹一条测试通知

不想全局安装？`npx ai-notify@latest install` 可尝鲜，但 hook 需要稳定路径，正式使用请全局安装。

## 卸载
ai-notify uninstall

## 支持的事件
| 事件 | 默认 |
|---|---|
| Claude Code 任务完成（Stop） | ✅ |
| Claude Code 出错停止（StopFailure：rate_limit 等） | ✅ |
| Claude Code 等待批准/等待输入（Notification） | ✅ |
| Claude Code 工具被中断（PostToolUseFailure） | ✅ |
| Claude Code 空闲提醒（idle_ping） | ❌ 默认关 |
| Claude Code 子代理完成（SubagentStop） | ❌ 默认关 |
| Codex 回合完成（agent-turn-complete，含回复摘要） | ✅ |

配置文件 `~/.ai-notify/config.json` 可打开默认关闭的事件。

## 已知限制
1. 纯 Esc 中断（无工具运行时）检测不到——Claude Code hooks 机制所限，非 bug
2. VSCode 扩展内的权限提示可能不触发通知（Claude Code 上游问题）；终端不受影响
3. Codex 仅支持回合完成通知（官方目前只开放该事件）
4. 仅 Windows 10/11

## 排障
- 看日志 `~/.ai-notify/log.txt`
- `ai-notify test` 验证 toast 链路
- 安装前会自动备份 `settings.json` / `config.toml`（`.bak.时间戳`）
```
